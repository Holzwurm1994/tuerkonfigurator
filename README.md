# Türen-Konfigurator · Schreinerei Altmühltal

Übungsshop für die Fachklasse Tischler (LF 11 Innentüren): Futtertüren nach DIN 18101 konfigurieren, prüfen und bestellen.
Installierbare Web-App (PWA), funktioniert nach dem ersten Öffnen auch offline. Alle Eingaben bleiben auf dem Gerät der Schülerin / des Schülers.

Veröffentlicht über GitHub Pages (Branch `main`, Ordner `/`).
